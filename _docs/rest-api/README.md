# ECHO: REST API

Use REST for things that happen once: logging in, managing contacts, creating chats and
loading old messages. For live chat, use the [WebSocket](../WEBSOCKET_PROTOCOL.md).

| Doc | What it covers |
|---|---|
| [basics.md](./basics.md) | Base path, auth header, response shape, errors and token codes |
| [users.md](./users.md) | Accounts, profile, finding people, contacts |
| [chats.md](./chats.md) | Chats, messages, hub statistics |
| [groups.md](./groups.md) | Groups and invite codes |
